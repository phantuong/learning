TTD Generator Contract v1

Generation pipeline

Problem Model → Visual Model → Choices → Solver → Validator → Deduplication → Publish Manifest

Hard rules

  • Exactly 4 choices.
  • Exactly one correct answer.
  • Answer is derived from the same model as the visual.
  • No mechanically generated near-duplicates.
  • Every question has an explanation tied to the model.
  • Rejected questions stay out of production.

Supported relational operators

same_shape, different_shape, same_color, different_color
left_of, right_of, above, below
more_than, less_than, exactly_one_more

Spatial cube rule

The expected cube is calculated by the rotation engine and compared against the four visual choices. Labels belong to cube faces; they never remain fixed to the screen.
